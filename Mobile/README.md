# MyTrash Web (PWA)

Official Progressive Web Application for the **MyTrash** waste management, recycling, and smart drop-off platform.

MyTrash Web is built with **React Native for Web** and **Expo**, providing a native-like mobile app experience directly in the browser across iOS, Android, and desktop devices without requiring an app store download.

---

## Features

- **Progressive Web App (PWA):**
  - Installable to home screen / desktop ("Add to Home Screen" prompt).
  - Standalone fullscreen display mode.
  - Offline-ready caching shell via dedicated Service Worker (`public/sw.js`).
  - Full W3C Web App Manifest (`public/manifest.json`) and high-resolution icons.
- **Smart Recycling Pickups:** Schedule and track waste collections.
- **Points & Rewards:** Eco-points wallet and leaderboard.
- **Supabase Integration:** Real-time data and authentication.
- **Dark / Light Theme:** Adaptive themes with optimized high-contrast styling.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone this repository:
   ```bash
   git clone <REPO_URL>
   cd <REPO_NAME>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Copy `.env.example` to `.env.local` and add your Supabase credentials:
   ```bash
   cp .env.example .env.local
   ```

---

## Available Scripts

### Development Server
```bash
npm run web
```
Starts the local development server at `http://localhost:8081`.

### Build PWA for Production
```bash
npm run build:pwa
```
Exports the production-ready static PWA bundle into the `dist/` directory.

### Preview Production PWA
```bash
npm run serve:pwa
```
Serves the `dist/` directory locally to test PWA installation and service worker caching.

---

## Deployment

The `dist/` folder generated by `npm run build:pwa` can be deployed directly to:
- **Vercel** (Build Command: `npm run build:pwa`, Output Directory: `dist`)
- **Netlify** (Build Command: `npm run build:pwa`, Publish directory: `dist`)
- **Cloudflare Pages** (Build Command: `npm run build:pwa`, Build output directory: `dist`)
- **GitHub Pages** / **Firebase Hosting**
